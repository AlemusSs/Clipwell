# Публикация обновлений

1. Создайте черновик GitHub Release с тегом v0.0.6 (далее v0.0.7 и т. д.).
2. До публикации прикрепите ровно один установщик: ClipwellSetup.exe или ClipwellSetup-0.0.6.exe.
3. Добавьте дату и описание изменений и опубликуйте выпуск, назначив его Latest.
4. Дождитесь успешного завершения Actions → Update application manifest. Оно проверит SHA-256 скачанного файла, переименует установщик в ClipwellSetup.exe и автоматически обновит latest.json.
5. Проверьте обновление из предыдущей версии приложения.

Если установщик прикреплён уже после публикации выпуска, запустите этот workflow вручную через Actions → Run workflow. При ошибке манифест не обновляется: проверьте наличие ровно одного подходящего установщика и повторите запуск.

Не редактируйте latest.json вручную. Источником номера версии служит тег, а размер и SHA-256 вычисляются из загруженного файла. Версия внутри установщика должна совпадать с тегом.

Исходники приложения публиковать не требуется. GitHub может несколько минут отдавать предыдущий latest.json из кэша; в таком случае повторите проверку позднее.
